# visual-editor/ (shared model + helpers)

The interactive-preview editor that used to live here (`preview.js`,
`line-view.js`, `palette.js`, `autoscroll.js`, `drag-reorder.js`, and the parked
`section-card.js` / `visual-editor.js`) was replaced by the CodeMirror lead-sheet
editor in `../lead-editor/` (see its CLAUDE.md). What remains is the pure,
DOM-free layer that editor and the rest of the app still use:

```
visual-editor/
├── model.js            # SongDocument: parseSong/serializeSong + pure edit ops
│                       #   (editor.js generates the submitted ChordPro with it; the
│                       #   round-trip test runs it over 300 real works)
├── syllables.js        # tokenizeLine: syllable / word seams for chord placement
└── wrap-section.js     # wrapSelectionAsSection: lines -> {start_of_X}/{end_of_X}
```

- **Data model**: a line is `{ lyrics, chords: [{chord, position}] }` — chords
  anchor to CHARACTER OFFSETS, ChordPro's native anchor. Round-trip invariant:
  `serializeSong(parseSong(x))` equals `x` after normalization (trailing
  whitespace, blank-line runs); metadata and unknown directives ride through.
- `wrap-section.js` extends a selection to whole lines, strips section directives
  inside it, trims edge blanks and auto-numbers the label positionally. The
  lead editor's section bar and label menu run it (via `lead-editor/section-ops.js`).
- `syllables.js` is a view-layer helper; `lead-editor/doc-model.js lineSeams`
  and the Chords-mode tap/strip read their seams from it.
  **Syllables (2026-10-27)**: `syllabify` is Liang hyphenation (US English
  patterns, `docs/vendor/hyph-en-us.js`, regenerated by
  `./scripts/vendor-hyphenation`; the algorithm is in-house, min 1 letter per
  side) plus lyric rules: a leading lone "a"/"o" before a consonant splits
  (a-way, o-ver; not when the patterns already cut at 2: an-gel, on-ly), `to`
  prefixes (to-night, to-day, to-mor-row, to-geth-er), `every`/`evening` as
  ev-ery / eve-ning, silent e is never its own syllable, every part keeps a vowel
  (a leading y before a vowel is a consonant). `syllabify(w).join('') === w`.
  The pattern module is lazy with the editor (`LAZY_MODULE_URLS`), never boot.
  `tokenizeLine` keeps its extra seams (hyphens, chords already inside a word).
  Regression: `docs/js/__tests__/fixtures/syllable-corpus.json`
  (`./scripts/build-syllable-corpus`: top 2000 in-word chord placements + top
  400 words) scored by `syllable-corpus.test.js` (>= 71% weighted match, 75.6%
  measured; no common one-syllable word split).

Tests: `visual-editor-model*.test.js`, `visual-editor-syllables.test.js`,
`visual-editor-wrap-section.test.js`.
